# DCN Lab 1: Network Devices and Cables (Theory)

A written lab covering the basics of network building blocks.

## Topics covered
- End devices (laptops, file servers, workstations) and why they are used
- Intermediate devices (routers, hubs, switches) and their role in connecting networks
- Straight-through vs crossover cables
- Remote access and the cable types used for it
